# 🪨📄✂️ Scissors-Paper-Stone-Game
Scissors Paper Stone CLI Game using Python 

A minimalist, zero-dependency command line interface (CLI) implementation of the classic **Scissors, Paper, Stone** game written in Python. 

---

## 🚀 Features

* **🧠 Smart Input Validation:** Automatically handles trailing spaces and mixed casing (e.g., `sToNe` or `  paper ` work flawlessly).
* **🔄 Persistent Game Loop:** Play as many rounds as you want without restarting the script.
* **📈 Live Scoreboard:** Tracks your score vs. the computer in real-time.
* **🧹 Clean Codebase:** Powered by a clean game mechanics dictionary instead of messy `if-else` nested trees.

---

## 🛠️ Prerequisites

Before running the game, ensure you have **Python 3.x** installed on your machine. You can verify this by running:

```bash
python --version
```

---

## 💻 How To Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory:**
   ```bash
   cd scissors-paper-stone
   ```
3. **Launch the game:**
   ```bash
   python game.py
   ```

---

## 🎮 Gameplay Mechanics

The game maps standard regional victory conditions dynamically:
* 🪨 **Stone** crushes **Scissors**
* 📄 **Paper** covers **Stone**
* ✂️ **Scissors** cuts **Paper**

To exit the game at any point, simply type `quit` into the terminal window during your turn prompt.
